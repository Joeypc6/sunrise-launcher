## What happens

A monster spawner whose `SpawnData` is `{entity:{id:"minecraft:ender_dragon"}}` never spawns the dragon. Test on Dev ba1f24e (easy difficulty):

- **Setup:** `Delay 1`, in a pit open 16 blocks up.
- **Result:** in 30 spawn attempts, the placement check (`mob_spawn_placement_check`) fired 33 times with `default: true`, so `noCollision` and the spawn rules passed. No dragon appeared.
- **Control:** a Wither and a Warden from the same setup spawn on the first attempt, and `/summon minecraft:ender_dragon` works.

In vanilla, `BaseSpawner.serverTick` creates the entity with `EntityType.loadEntityRecursive(tag, level, EntitySpawnReason.SPAWNER, ...)`. Any entity type that can be created spawns: the dragon, and non-mob entities such as an armor stand, a boat, a minecart, a primed TNT or an item. Only the `Mob` steps are skipped for them (`checkSpawnRules`, `checkSpawnObstruction`, `finalizeSpawn`).

## What happens on main (d48a875844)

`crates/sunrise-sim/src/mobs/spawner.rs`, `server_tick`:

1. `l.spawner_type(&id)` finds the type. `SpawnerTypeFacts` has a row for every registered type, mobs or not ("Every registered type must have a complete row, whether or not it is a mob"), so the dragon gets past `EntityType.by`, `noCollision` and the spawn rules.
2. Then:

```rust
// loadEntityRecursive: a type the game cannot create delays.
let Some(mob) = l.mob_type(&id) else {
    self.delay(random, events);
    return;
};
```

`mob_type` reads `res.mob_types()`. That table has the Wither and the Warden but not `minecraft:ender_dragon`, nor any non-mob type, so the spawner resets its delay on every attempt.

The game can create these entities: `/summon` and `EntityType.loadEntityRecursive` in `data_server.rs` (`load_configured_entity`) create the dragon and non-mob entities. Only the spawner's path requires a mob type. `crates/sunrise-gameplay/src/game/mobs/spawner.rs` `plan_spawner_mob` also starts with `self.common.res.mob_types().get(r.id)?`.

## Expected

The spawner creates every type `loadEntityRecursive` can create:
- For a `Mob`: the current path.
- For any other entity (the dragon, an armor stand, a boat, a minecart, TNT): load the configured entity at the chosen position and add it with its passengers. This skips only what vanilla skips for non-mobs (`Mob.checkSpawnRules`, `checkSpawnObstruction` and `finalizeSpawn`). The `max_nearby_entities` count and the delay work as they do now.

## Why a mod hits it

Apothic Spawners (a port of the NeoForge mod) lets players set a spawner to any entity type and add modifiers. On Sunrise, the dragon and every non-mob type it accepts sit idle.

## Vanilla reference

- `BaseSpawner.serverTick`: `EntityType.loadEntityRecursive(...)`; `if (entity instanceof Mob mob) { checkSpawnRules / checkSpawnObstruction / finalizeSpawn }`; `level.tryAddFreshEntityWithPassengers(entity)`.
- `EnderDragon` extends `Mob`, but in Sunrise the client and the mob table treat it apart (multi-part); compare #6050.
