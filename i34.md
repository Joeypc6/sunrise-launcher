## What a mod needs

To ask whether a block falls (Java's `block instanceof Fallable`, or `instanceof FallingBlock`). Mods use it after editing many blocks at once: when a large explosion or a mass break clears a region, the mod schedules the edge blocks that can fall, so sand, gravel, concrete powder, anvils and pointed dripstone come down as they would after a vanilla explosion. Other uses: a builder or mover that won't place a falling block over air, or a tool that treats gravity blocks apart.

Example: a reactor in a mod in development blows a sphere out of the world. Afterwards it updates the falling blocks on the crater's rim. In the port, nothing answers "does this state fall", so it keeps a hand-written list of vanilla ids. Mod blocks that fall (for example one declared on a falling behaviour template) are missed, and the list has to follow every version.

## What happens on main (c59f592366)

- `BlockStates::block_class(state, class) -> Result<Option<bool>, LevelReadError>` (`block/block_states.rs`, #3322 / #3368) reads the engine's own `instanceof` classification. A mod block declared on a vanilla template belongs to that template's classes.
- `BlockClass` has `Stair`, `Entity`, `IronBars`, `StainedGlassPane`, `TrapDoor`, `Bonemealable` (#5364), `Slab`, `Wall` and `Fence`, but nothing for falling.
- No tag stands in for it: vanilla has no "falls" tag.
- The engine knows which blocks fall (its falling-block code spawns them), but no read exposes it.

## Proposal

Add one class, the same way `Bonemealable` was added:

```rust
/// `Fallable`: the blocks that can fall as a falling block entity (`FallingBlock` and its
/// subclasses: sand, gravel, concrete powder, anvils, the dragon egg, suspicious sand and
/// gravel), and pointed dripstone. A mod block on one of their templates included.
Fallable,
```

If a mod needs the narrower test, a `FallingBlock` class can be added beside it (pointed dripstone is `Fallable` but not a `FallingBlock`). Either answers once per state; a mod can then ask in a loop over many states.

## Vanilla / NeoForge reference

- `net.minecraft.world.level.block.Fallable` (`onLand`, `onBrokenAfterFall`, `getFallDamageSource`). Implemented by `FallingBlock` and `PointedDripstoneBlock`.
- `FallingBlock.tick` / `FallingBlock.isFree`; `FallingBlockEntity.fall`.
- NeoForge: `IFallableExtension` (`fallingTick`); mods test `block instanceof Fallable`.
