## Group 1: two tests compare against a fixture checked out with CRLF (cause found)

- `extras::tests::serialize_keeps_the_format_of_main`
- `light_storage_tests::light_reads_follow_vanilla_storage`

Both `include_str!` a committed text file and compare it with a string built with `\n`:
- `extras.rs` reads `tests/fixtures/extras_default.txt` and `extras_set.txt`;
- `light_storage_tests.rs` reads `tools/light_storage_scenario.txt` and `tools/light_storage_witness.txt`.

With `core.autocrlf=true` the fixtures check out with `\r\n`. The assertion's `right` side shows `\r\n` on every line, and `left` shows `\n`. Fix: add those paths to `.gitattributes` with `text eol=lf`, as #6015 did for the signed fixtures, and the `spirv_dump` lines already do. Alternatively, have the tests normalise line endings.
