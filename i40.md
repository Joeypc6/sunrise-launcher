## The gap

In vanilla, a dead player's body stays in the level until its death animation ends (death tick 20). Until then it counts as an entity that blocks building, and pressure plates count it too (`EntitySelector.NO_SPECTATORS` has no alive check).

On Sunrise, a LAN guest's body is now honoured for a guest's own block placement (#6181). Two other paths still drop a dead guest at once:

- **The host placing a block outside a guest's turn.** Guests come from `lan_block_trigger_boxes` (`lan_mobs.rs:128`), which filters out dead guests.
- **Pressure plates and other block triggers.** The same list drives them, so a dead guest's body stops pressing a plate immediately instead of after its 20 death ticks.

## Expected

Keep a dead guest in `lan_block_trigger_boxes` until its body is removed, as vanilla keeps a dead player in the level. Then host placement and pressure plates match vanilla.

## Context

Found while answering a review point on #6181, which made a guest's own placement and the mod API 1:1 but left these two paths unchanged so the PR doesn't alter redstone behaviour.
