1. **Conditions.** Decided once while building the root, as the worldgen and modifier files in the same function are. `load_conditions.rs:293-307`: for each winning damage type file the builder evaluates `neoforge:conditions` with the owning load's `conditions` (`allows_file`; an invalid condition lands in `check_errors()` like the modifier files'), leaves a failing file out, and writes a passing one through the new `without_conditions` (`load_conditions.rs:680`), which drops the key and unwraps `neoforge:value` from the raw text, so `Items::catalog(root, &PackOverlay::NONE, ...)` no longer re-evaluates it with the vanilla-only inventory. A type gated on its own mod is kept, a negated one is dropped when the mod is loaded. The comment that said every reader evaluates them is replaced.
2. **Tests** (`mod_content_load_conditions_tests.rs`, through the root alone with `PackOverlay::NONE`): `a_gated_mod_damage_type_is_decided_once_for_the_root_alone_readers` covers a gated and a negated definition, present and absent.
