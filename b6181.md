## What and why

Fixes #6036. A mod that writes a block from its own placement code cannot ask what `BlockItem.canPlace` asks first: whether an entity that blocks building stands in the state's collision shape. Applied Energistics 2 places cable buses this way and checks `level.isUnobstructed(state, pos, CollisionContext.empty())` first, so a cable is not placed inside a mob or a player. A mod could only approximate it with `visit_entities_in` and `has_collisions`.

What the commit adds:
- `LevelRef::is_unobstructed(host, pos, state) -> Result<bool, LevelReadError>`, backed by `LevelCollisionBackend::level_is_unobstructed`. It is `CollisionGetter.isUnobstructed(state, pos, CollisionContext.empty())`: `EntityGetter.isUnobstructed(null, shape)` over the supplied state's collision shape moved to `pos`.
- It is the empty-context form of the test `BlockItem.canPlace` makes. `canPlace` passes `CollisionContext.placementContext(player)`; no player context is exposed, so a shape that depends on the entity context is its empty-context shape.
- The state need not be the block stored at `pos`. No entity is excepted. A state with an empty collision shape is always unobstructed.
- An entity counts when it is alive, not a spectator and `blocksBuilding` (players, mobs, minecarts, boats, armor stands that are not markers, end crystals, primed TNT, falling blocks), and when its box overlaps the shape itself, not only the shape's bounds.
- It reads open server levels, active or parked. `Err(Stale)` for a stale handle, `Err(Unavailable)` on a client, when the level cannot be read, or when the state's collision shape cannot be evaluated (that error is not taken as an empty, unobstructed shape).
- The datapack placement check's unit-cell test is split into `is_shape_unobstructed(level, world, shape)`, which the new read shares. The cell check now calls it with `VoxelShape::block()` moved to the position.
